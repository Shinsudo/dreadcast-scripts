# Scripts Dreadcast

Deux scripts Tampermonkey pour [Dreadcast](https://www.dreadcast.net). Ils ne cliquent jamais et n'envoient rien à ta place (détail en tête de chaque script).

| Script | Installer |
|---|---|
| **DC Confort** : l'écran du jeu et le forum plus lisibles, le Courrier façon DDM V2 | [dc-confort.user.js](https://raw.githubusercontent.com/Shinsudo/dreadcast-scripts/main/dc-confort.user.js) |
| **DECK 2 — pont** : lit ce que tu ouvres en jeu et le transmet à DECK 2 | [deck-pont.user.js](https://raw.githubusercontent.com/Shinsudo/dreadcast-scripts/main/deck-pont.user.js) |

Clique sur le lien : Tampermonkey propose l'installation. Ensuite, il vérifie tout seul s'il existe une nouvelle version (réglable dans Tampermonkey › Paramètres › « Vérifier les mises à jour des scripts »).

Ce dépôt est rempli automatiquement : ne pas modifier les fichiers ici.
